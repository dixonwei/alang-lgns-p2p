# 阿郎老师 LGNS 双链互助交换站

面向学员的 ANUBIS ↔ Polygon LGNS P2P 互助交换前端与本地撮合服务。

## 启动方式

双击 `启动阿郎老师交换站.cmd`。当前电脑已内置 Node 运行环境；复制到其他电脑时，如果 `runtime\node.exe` 不存在，则需要安装 Node.js 20 或更高版本。

浏览器会自动打开：

`http://127.0.0.1:8170/`

停止网站：双击 `停止网站.cmd`。服务日志位于 `data\server.log`。

## 当前功能

- ANUBIS ↔ Polygon LGNS 双向订单
- 兑换比例由卖出方在每笔订单中自行填写
- 平台不设定固定汇率，只负责展示、签名验证、撮合和记录
- 平台服务费固定 `3%`，管理员不能修改
- 卖方发布订单、买方钱包签名接单
- 订单最长有效期 24 小时
- 公开订单簿和管理员订单审核
- 钱包签名由服务端真实校验
- 不读取私钥、助记词或钱包密码
- 桌面端与手机端自适应

## 管理员入口

浏览器打开：

`http://127.0.0.1:8170/admin.html`

管理员初始密码文件：

`data/admin-password.txt`

修改密码方式：编辑该文件后重启网站。

管理员只能审核、查看和取消未接单订单，不能设置兑换比例，也不能修改 3% 服务费。

## 当前阶段说明

当前首版只完成公开订单簿、报价、钱包签名和撮合管理。

双链 HTLC 担保合约尚未部署，因此当前页面不会要求用户向任何地址转币，也不会执行链上锁仓。正式接入合约并完成独立审计前，请勿在平台外提前转账。

## 数据文件

- `data/store.json`：订单与固定平台配置
- `data/admin-password.txt`：管理员密码

`data/` 已在 `.gitignore` 中排除，公开 GitHub 时不会上传本地订单和管理员密码。

备份网站时，请同时备份 `data` 文件夹。

## 技术说明

- 纯 Node.js 本地服务，无需 npm 安装依赖
- 内置 `ethers` 用于钱包签名验证
- 网站默认只监听本机 `127.0.0.1`
- 生产公网部署前，需要增加 HTTPS、数据库、用户登录体系、管理员多签、HTLC 合约和独立安全审计
## 链上担保合约

`contracts/LGNSHTLC.sol` 已加入双链 HTLC 基础源码和部署检查说明。该合约当前未部署、未审计，不能用于真实资金。
